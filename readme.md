# Web Dev Resources

Extra material that sits alongside the class notes: readings, deeper dives,
practice, and common mistakes. The class notes themselves live in the
teacher's repo: https://github.com/mrinal1224/2029-Group-C-WebDev

## How to use this repo
1. Find your class in the table below.
2. Open the notes (teacher's repo) first, then the extras here.
3. Found something good? Add it, see [CONTRIBUTING.md](CONTRIBUTING.md).
